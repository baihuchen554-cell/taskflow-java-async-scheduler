# 管理页面设计与验收

管理页面使用原生 HTML、CSS、JavaScript，由 Spring Boot 直接提供。它没有独立的前端构建过程，也不依赖外部 CDN；适合阅读、运行和演示这个 Java 项目。

## 设计参考

- 设计图：[taskflow-concept.png](design/taskflow-concept.png)，原生尺寸 1536 × 1024。
- 生成方式：内置 Image Gen，已使用 `view_image` 查看原图。
- 设计提示词要点：TaskFlow 中文任务调度台，白色窄侧栏、冷灰背景、靛紫主按钮、开放式四项统计、状态筛选、任务表格、分页；完整主屏幕，不添加图表或营销内容。
- 固定文案：TaskFlow、任务调度、任务调度台、提交任务，让后台处理。每一次执行，都有迹可循。、新建任务、总任务、执行中、已完成、失败、全部任务、全部、等待中、重试等待、已取消、任务、类型、状态、执行次数、创建时间、操作、上一页、下一页、每 3 秒自动刷新。

## 设计系统

| 部分 | 实现约定 |
| --- | --- |
| 页面背景 | 冷灰 `#f7f8fc`，侧栏和表格为纯白 `#ffffff` |
| 文字 | 深色 `#17213a`，辅助文字 `#74809a` |
| 主色 | 靛紫 `#6251de`，选中背景 `#f0edff` |
| 语义色 | 成功绿 `#269357`、失败红 `#d93643`、重试琥珀 `#bc7b12` |
| 排版 | 系统无衬线字体，中文使用 Microsoft YaHei 等本地回退，不依赖下载字体 |
| 容器 | 单一表格面板、开放式统计区域；无装饰性嵌套卡片 |
| 圆角 | 主面板 9px、按钮 7px、弹窗 12px |
| 图标 | 原生 SVG 线性图标，统一描边和尺寸；图标仅辅助表达已有按钮功能 |
| 窄屏 | 800px 以下侧栏变顶部导航；500px 以下统计变为两列，表格在自身容器中横向滚动 |
| 弹窗 | 创建与详情使用原生 `dialog`，支持 Esc、焦点管理和可访问名称 |

## 与设计图有意不同的部分

1. 设计图的任务、数量和日期用于表现布局；实现从真实 API 读取，不内置这些示例数据。
2. 设计图中成功任务旁的“取消”不符合状态约束；实际只允许取消 `PENDING` / `RETRY_WAIT`，只允许重试 `FAILED`。
3. 连接状态显示真实数据库类型和工作线程数，不展示包含凭据风险的连接串。
4. 状态筛选会将标题变为对应状态名称；筛选计数来自后端分页结果，总览始终展示全量统计。
5. 创建、详情、空状态、错误状态与移动端沿用主设计的字体、颜色、边框和间距，属于完成操作流程所需的补充状态。
6. 文本统计明确说明“词数按空白分隔，不做中文分词”，与后端实现一致。

## 静态检查与交互约束

- `node --check src/main/resources/static/app.js` 检查 JavaScript 语法。
- 所有数据来自 `/api/tasks`、`/api/tasks/stats`、`/api/system` 及任务详情/日志接口。
- 后端文本经过 HTML 转义；错误消息使用 `textContent`；任务内容不会作为脚本执行。
- 页面每 3 秒刷新；页面不可见时暂停轮询；已有请求未完成时不叠加同类轮询。
- 切换筛选或分页会中止旧请求，并以序号阻止旧响应覆盖新结果。
- 详情关闭后中止请求；内容不变时不替换 DOM，内容变化时尽量保留操作按钮焦点。
- 提交中禁用表单与关闭按钮，防止重复提交；隐藏的演示参数不参与浏览器表单校验。
- 取消/重试按任务 ID 去重，后端 `409` 冲突会显示可读提示。
- 单次请求超时为 15 秒，写操作超时会提示先刷新确认结果，不自动重复提交。
- 重试次数和执行次数分开表达：执行次数累计，最大重试次数是每轮预算。

## 浏览器验收记录

最终浏览器验收由集成阶段补充，以下条目在实际运行后才能记为通过：

| 核对点 | 设计依据 | 需要观察的浏览器结果 |
| --- | --- | --- |
| 首屏结构 | 白色侧栏 + 右侧主区域 + 开放式统计 + 单一表格 | 对照 1536 × 1024 截图，确认顺序、比例与留白 |
| 文案 | 上方固定文案清单 | 检查未新增营销标题，动态值单独处理 |
| 颜色 | 设计系统色值 | 白色/冷灰/靛紫与语义色保持一致，无额外渐变 |
| 字体与控件 | 标题 34–36px、表格 14–15px、统一按钮 | 没有截字、浏览器默认控件字号或意外换行 |
| 容器与图标 | 单表格面板，线性 SVG | 不出现额外卡片，刷新/关闭/新增图标完整 |
| 核心流程 | 新建 → 状态变化 → 详情/执行记录 | 文本统计、演示重试、延迟取消、失败重试都调用真实 API |
| 窄屏 | 两列统计与内部横向表格 | 390px 宽度无整页横向溢出，弹窗可滚动且按钮可达 |

完成集成验收时，将实际截图路径、浏览器方式、尺寸、修复项和仍存在的差异附在本节。静态检查不等同于浏览器验证。

### 2026-10-30 实际验收结果

内置浏览器两次 CDP 超时，因此改用本机 Playwright 驱动 Chrome 验证。桌面视口为设计图原生尺寸 1536 × 1024，手机视口为 390 × 844。设计图与最终浏览器截图均通过 `view_image` 直接检查。

- 首屏：侧栏、标题、四项开放式统计、筛选、表格、分页顺序与设计参考一致。
- 文案：固定标题、说明、操作名称已逐项核对；真实数量、日期、任务名称和数据库信息属于有意替换。
- 配色：保留白色侧栏和表格、冷灰背景、靛紫操作色及绿/红状态色，无额外装饰渐变。
- 排版：标题、标签、行间距和按钮字号一致；首页每页 5 条任务，使原生视口内能看到分页。
- 图标和容器：线性图标、开放统计区和单一表格面板，未引入多余卡片。
- 交互：已验证文本任务提交与结果、模拟失败后自动重试的两条记录、筛选、翻页、手机端提交；API 验证另覆盖手动重试与取消。
- 响应式：390px 视口下 document.scrollWidth = 390，无整页横向溢出；表格在自身容器中滚动，弹窗可滚动。
- 浏览器检查：未发现 JavaScript 页面异常。最终设计对照无未解决的明显布局问题。
